# BLAZING-WAY Super Admin Android app

This Android wrapper opens the existing HTTPS Super Admin dashboard at:

https://lazimhosen718-commits.github.io/blazing-way-admin/admin.html

Build a debug APK with the GitHub Actions workflow **Build BLAZING-WAY Super Admin APK**. The artifact is an unsigned debug APK for testing, not a Play Store release. The dashboard still requires the authorized Super Admin account; this app does not create or bypass admin access.
